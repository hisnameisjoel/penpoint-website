What's Next?

Built-in Help Guide

Click the ? icon in the top-right corner of the app at any time to open the help guide. It covers every feature, with step-by-step walkthroughs.

Start with the Demo Book

Penpoint comes with a pre-built demo book so you can explore every feature before touching your own work. Poke around, break things, get comfortable.

Import Your Manuscript

Already have a manuscript? Import from Word, EPUB, Markdown, or plain text. Penpoint detects chapter boundaries automatically. Then scan chapters to find your characters.

Automatic Updates

Penpoint checks for updates every time you launch. When a new version is available, it downloads and installs in the background. You'll always be on the latest version.

Upgrading from the free trial?

Installing the full version replaces the trial automatically. All your books, chapters, and worldbuilding are preserved exactly where you left them. Just download, install, and keep writing.

Installation Guide

  1. Your browser may warn that the file "isn't commonly downloaded." This is normal for new software — click "Keep" or "See more → Keep anyway" to save the file.
  2. Run the downloaded .exe installer.
  3. Follow the installation prompts — Penpoint will launch when finished.
  1. Open the downloaded .dmg file.
  2. Drag Penpoint to your Applications folder.
  3. Open Penpoint from Applications — it will launch normally.

.deb package (Ubuntu, Debian, Pop!_OS, Mint)

  1. Double-click the downloaded .deb file — your package manager will handle the rest.
  2. Find Penpoint in your app launcher and open it.

.AppImage (works on any distro)

  1. Make the AppImage executable. Open a terminal and run:
    chmod +x Penpoint_*.AppImage
  2. Double-click the .AppImage file to launch Penpoint, or run it from the terminal:
    ./Penpoint_*.AppImage
