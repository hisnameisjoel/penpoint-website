Windows startup help

Penpoint needs Microsoft WebView2.

WebView2 is the Windows component Penpoint uses to display the app. It is already included on most Windows 10 and Windows 11 computers. If Penpoint cannot find it, the component may be missing or damaged.

If WebView2 is missing

  1. Download Microsoft's small WebView2 installer.
  2. Run the downloaded installer and let it finish.
  3. Restart Windows, then open Penpoint again.
Download WebView2 from Microsoft

If Microsoft says WebView2 is already installed

Windows has recorded WebView2 as installed, but the runtime may be damaged or unavailable to your account.

  1. Restart your computer.
  2. Close Microsoft Edge, Teams, Outlook, Widgets, and any other open apps.
  3. Open Windows Settings > Apps > Apps & features.
  4. Find Microsoft Edge WebView2 Runtime. Select Modify, then Repair.
  5. Restart Windows and open Penpoint again.

If Repair is unavailable or does not work, uninstall WebView2 from Apps if Windows offers that option. Restart, then download the Evergreen Standalone Installer from Microsoft and run it as administrator to reinstall WebView2.

Open Microsoft's WebView2 downloads

Do not manually delete Microsoft folders or edit the Windows registry. Those changes can affect every application that uses WebView2.

Still cannot open Penpoint?

Email support@penpoint.app with:

  • A photo or screenshot of the error.
  • Your Windows version. Press Windows key + R, enter winver, and take a screenshot.
  • Whether the laptop is managed by your workplace or school.

Repairing WebView2 does not remove or change your Penpoint books.
