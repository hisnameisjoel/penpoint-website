Text Block

A short text block (a section on your character sheet) for brief character information like nicknames, titles, roles, and more. Click any text block to edit it, or view its contents at a glance. Ideal for quick blurbs that don't need formatting like bold, italic, and lists.

Text Blocks also work on the Chapters page — drop one into a scene's layout for per-scene snippets like a working title or one-line summary. See Chapter Block Types.

Common Uses

  • Nicknames: What other characters call this person
  • Titles: Formal titles, ranks, or positions
  • Roles: Story role (Protagonist, Mentor, etc.)
  • Pronouns: Preferred pronouns
  • Species/Race: In fantasy or sci-fi stories
  • Quick descriptions: "grumpy blacksmith" or "cheerful thief"

Tip: If you are commonly using a group of attributes that apply to more than one character, you might consider using a Trait Block instead. The Trait Block has preconfigured, selectable text options that can be reused across multiple characters.

Configuration

To configure a Text Block, go to Settings > Character Sheet Setup and click on the block to reveal its settings panel.

  • Block Title: Custom title for this text block (e.g., "Nickname", "Title", "Pronouns")
  • Include in Quick Create: When checked, this block appears in the Quick Create menu (the streamlined form for adding new characters quickly) for faster character creation

Tip: Running out of room or want to add formatting like bold, italic, and lists? Use a Paragraph Block instead.
