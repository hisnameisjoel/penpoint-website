Paragraph Block

A multi-line text field with formatting support for detailed character information like backstories, physical descriptions, and personality notes.

Paragraph Blocks aren't just for character sheets — you can also add them to chapter scenes for descriptions, notes, or any longer-form text per scene. See Chapter Block Types.

Formatting

Use the toolbar buttons to format your text:

  • Bold, italic, underline, strikethrough
  • Block styles via the Style dropdown: Paragraph, Quote, Heading 1, Heading 2, Heading 3
  • Bulleted and numbered lists
  • Indent and decrease indent (move text back to the left)
  • Hyperlinks to external websites
  • Inline images
  • Horizontal line (a divider across the block)
  • Undo and redo

Common Uses

  • Physical descriptions and mannerisms
  • Backstory and history
  • Personality and quirks
  • Motivations and goals
  • Relationship descriptions

Tip: Create separate Paragraph Blocks for different aspects (one for appearance, one for personality, one for backstory) rather than one massive block.

@ Mentions

Type @ to create clickable links to other characters, locations, items, chapters, notes, or arcs. This makes it easy to navigate between related content directly from your character sheets.

When you type @, a dropdown menu appears with search results. Use the Up and Down arrow keys to navigate through the options, then press Enter to select. A clickable link is automatically inserted into your text.

Tip: The @ mention system works in any Paragraph Block throughout Penpoint (and well beyond; see @Mentions for everywhere it works). Write "Trained under @MasterKai before joining @Sarah's rebellion" to create quick links to other characters.

Note: Paragraph Blocks don't appear in Cards View (a compact visual layout for your character list). Use Text Blocks for brief info that should display on cards.

Configuration

To configure a Paragraph Block, go to Settings > Character Sheet Setup and click on the block to reveal its settings panel.

  • Block Title: Custom title for this paragraph block (e.g., "Physical Description", "Backstory", "Personality")
  • Include in Quick Create: When enabled, this block appears in the Quick Create form (the streamlined form for adding new characters quickly)
