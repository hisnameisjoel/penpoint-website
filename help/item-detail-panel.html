Item Detail Panel

When you select an item from the list, its detail panel appears on the right side of the screen. In View mode, you can read all the item's information. Switch to Edit mode to make changes.

Header

The top of the panel shows the item's profile picture (or type icon if none is set) alongside the name. If the item has the single-character restriction enabled, a "Single Character" badge appears below the name. Click a profile picture in View mode to open it full-size.

Use the Edit/View toggle button in the header to switch between reading and editing modes.

Type

Displays the item's type with its icon. This section shows what category the item belongs to, based on the types you've configured.

Importance

Shows the item's importance level: Primary, Secondary, or Background. This helps you track which items are central to your plot versus minor background details.

Description

The description section displays rich text content about the item. You can include detailed information about the item's appearance, history, powers, or significance to your story.

In View mode, the description is displayed with all formatting intact. If no description has been added, you'll see "No description provided"

Characters

Lists all characters connected to this item. Each character is shown with their name (clickable to navigate to that character) and their importance level badge. If a relationship note has been added, it appears in italics beneath the character's name — for example, "forged it" or "guards it."

The section header shows the count: "Characters (2)" for example. If the item isn't assigned to any characters, you'll see "Not assigned to any characters."

Tip: Click a character's name to jump directly to their detail panel, making it easy to explore connections between items and characters.

Chapters

Shows which chapters this item appears in. Each chapter displays its number and title, and is clickable to navigate directly to that chapter. In Edit mode, use the Add to Chapter button to assign the item to additional chapters.

Events

Lists the key moments this item is part of, like the night it was stolen or the duel it was drawn in. The same event can also appear on the characters and locations involved: it's one event in several places, not a copy. In Edit mode, use Add event to add an event you've already made, or create a new one. Removing an event here only takes it off this item; it stays on everyone else it involves.

For how events work across your book, see Events.

Locations

Shows which locations this item is found at. Each location is clickable to navigate directly to it. In Edit mode, use the Add to Location button to assign the item to additional locations.

Tags

Displays all tags assigned to the item with their colored dots for visual identification. Tags help you categorize and filter items across your project.

For more information about creating and managing tags, see Managing Tags.

Tip: Press Ctrl+E (Cmd+E on Mac) to quickly toggle between View and Edit modes without reaching for the mouse.
