Importing Data

The Import Wizard brings markdown files (the text files Penpoint creates when you export) back into your book. It works with all six kinds of worldbuilding: characters, locations, items, notes, chapter outlines, and arcs. A file you exported from this version comes back in cleanly, with every detail, picture, and @Mentions link landing exactly where it was. Best of all, before anything is written you'll see a summary of what each file contains and anything new that would be created. You can import a single file or an entire folder at once.

Note: Files exported by this version of Penpoint import back perfectly. Older exports, filled-in template sheets (the blank fill-in files Penpoint can generate), and even hand-written files still import too. Penpoint reads them as best it can and shows you what it understood before writing anything. The one exception: a file exported by a newer version of Penpoint than you're running can't be imported until you update.

How to Import

Go to Settings > Import/Export and click "Open Import Wizard" in the Import Data section. The wizard follows these steps:

  1. Choose What to Import - Pick a type (Characters, Locations, Items, Notes, Chapters, or Arcs), or choose Everything to bring in a whole export folder. Penpoint reads each file by its contents, so you don't have to get this exactly right; whatever you pick, each file still imports as what it actually is
  2. Before You Import - A quick page of tips on formatting and templates
  3. Choose Import Mode - Select whether to import a single file or an entire folder
  4. Automatic Check - Penpoint double-checks the files for anything that might trip up the import
  5. Review Results - See what Penpoint found in each file (every entry, and anything new it would create) along with any warnings, before you import
  6. Resolve Conflicts - Decide how to handle entries with duplicate names
  7. Complete Import - View statistics on what was created, updated, or auto-generated

File Checking

Penpoint checks each file for common issues before importing:

  • Whether the file matches the format Penpoint expects
  • Required fields like names
  • Valid values for importance levels and other settings
  • Duplicate names within the same file

Files with errors can't be imported until fixed. Files with warnings can usually be imported anyway - Penpoint will skip or default any problematic values. If you're importing a folder and one file has a problem, Penpoint skips just that file and imports the rest.

Conflict Resolution

When an imported file has the same name as something already in your book, you'll be asked to choose how to handle it:

  • Overwrite existing - Replace the existing entry with what's in the file, including its links, tags, and traits. This permanently replaces the original, so if you're not certain, make a backup of your book first — the note just below shows how, and how to restore it.
  • Skip this file - Keep what you already have and import nothing from this file
  • Keep both - Import as a new entry with a numbered name (e.g., "Sherlock Holmes (1)"), leaving the original untouched

Your choice applies to the whole file, so if one file holds several entries that already exist, one decision covers all of them. When you're importing many files at once, use the "Overwrite All", "Skip All", or "Keep Both (All)" buttons to handle them the same way in one click.

Note: Before importing with Overwrite, it's a good idea to create a manual backup of your book in Settings > Storage & Backups. If anything doesn't look right after importing, you can restore from that backup. For more details, see Backup & Restore.

Auto-Created Placeholders

When your markdown files mention other characters, locations, items, or chapters (like a character's relationships or chapter appearances), Penpoint checks if those already exist in your book. If they don't, it creates placeholders with just a name so the connections work correctly. These placeholders appear in your normal character, location, item, and chapter lists alongside your other entries.

Tip: After importing, you can fill out the auto-created placeholders or import additional files for them. This makes it easy to build out your world piece by piece.

Import Statistics

When the import completes, you'll see a summary showing:

  • How many new entries were created
  • How many existing entries were updated
  • Which placeholders were auto-created from mentions in your files
  • Any warnings that occurred during import

Note: Importing new entries won't change your existing data. If you chose Overwrite for any conflicts, you can restore from a backup you created beforehand. See Backup & Restore for details on creating and restoring backups.
