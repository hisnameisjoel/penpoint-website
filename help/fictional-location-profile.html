Location Detail View

The detail panel (the area on the right side of the screen where your location's information appears) shows everything about the selected location. Like the Characters page, you can switch between View mode (for reading your location at a glance) and Edit mode (for making changes to any field).

Learn more about the difference between these modes in View Mode vs Edit Mode.

Header Section

The header shows the location's path, icon, name, and the View/Edit toggle.

Location Path

The location path displays the full hierarchy from the root to the current location. Click any location in the path to navigate directly to it.

See Location Hierarchy for more details about location path navigation.

Location Icon

Each location has a customizable icon. In Edit mode, click the icon to open the icon picker and choose from categorized icon sets (Buildings, Nature, Regions, Infrastructure).

Learn more in Location Icons.

Location Name

In Edit mode, the name becomes an editable field. Names can be up to 35 characters and auto-save as you type.

Profile Picture

Locations can have a profile picture, just like characters. In Edit mode, click the image area to upload a photo, or drag and drop an image file onto it. You can crop and reposition the image before saving.

In View mode, click the picture to see it full-size. To change or remove an existing image, switch to Edit mode and hover over the image to reveal edit and remove buttons.

Type & Importance

Two side-by-side dropdowns let you set the location's type and importance level.

Location Type

Select a location type from your customized types (City, Region, Building, etc.). Types help you organize and sort locations. If you don't see a specific type or want to modify them, manage types in Settings > Location Types.

Importance Level

Like characters, locations have three importance levels: Primary (major settings), Secondary (supporting locations), and Background (minor locations).

Note: All fields auto-save as you work: name, description, type, importance, and icon. There is no save button; your changes are preserved automatically.

Description

The description field uses a text area that supports formatting like bold, italic, and links. You can also type @ followed by a name to create a clickable link to another character, item, or location.

The description editor works the same as the Paragraph Block: you can use bold, italic, and @Mentions to create clickable links to your characters, items, and locations.

In View mode, the description appears as formatted text with @ mention links. Click any mention to navigate directly to it.

Characters

This section shows which characters are currently at this location (useful for tracking who is where in your story).

In View mode, click any character to navigate to their detail page. In Edit mode, the dashed Add character row at the bottom of the list opens an inline search that suggests characters not already placed here. Hover any assigned character to reveal the trash icon — removing only unlinks them from this location; it does not delete the character itself.

Items

The Items section works identically to Characters, but for items at this location. Each item shows its archetype icon next to the name, and clicking it in View mode navigates to the item's detail page. In Edit mode, use the dashed Add item row to assign an existing item, or pick Create New Item… from the search dropdown to create one on the fly.

Events

Lists the key moments that happen at this location. The same event can also appear on the characters and items involved: it's one event in several places, not a copy. In Edit mode, use Add event to add an event you've already made, or create a new one. Removing an event here only takes it off this location; it stays on everyone else it involves.

For how events work across your book, see Events.

Sub-locations

If a location has children, the sub-locations section appears showing the locations directly inside it in a grid layout.

Each sub-location displays with its icon and name. Click any sub-location to navigate to it instantly.

Tip: The sub-locations grid only shows the locations directly inside it, not locations nested further down. This keeps the view focused and uncluttered.

Tags

The tags section works identically to character tags. Tags are universal across characters, items, chapters, locations, and notes; a tag created for a location is available everywhere.

Learn more about creating and managing tags in Managing Tags.

Deleting a Location

In Edit mode, a Delete Location button appears at the bottom of the panel. Clicking it opens a confirmation dialog that explains exactly what will be removed and asks you to confirm before anything is deleted. If the location has sub-locations, the dialog gives you the option to preserve them or delete them along with the parent. This action cannot be undone, so review the confirmation carefully.
