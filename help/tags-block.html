Tags Block

Tags are color-coded labels you can assign to characters, locations, items, chapters, and notes. Think of them as a powerful organizational system that works everywhere.

The Tags Block also lives on the Chapters page, where you can attach tags to the whole chapter and to individual scenes. See Chapter Block Types.

The Tags Block appears differently depending on whether you're in View Mode or Edit Mode. In View Mode, tags are shown as plain labels you can't change. In Edit Mode, you can add or remove them. See View Mode vs Edit Mode for details.

Once tagged, all your related content can be viewed together in the Tags Viewer, making it easy to see all characters, locations, and other elements that share a tag. This makes tags essential for finding like-content across your entire book.

Tag Groups

If you've filed your tags into Tag Groups, the list of available tags is split into sections with a heading for each group, and anything unfiled sits under Ungrouped at the bottom. Clicking a heading folds that group away, and it stays folded everywhere else you pick tags until you open it again, so a category you're not using today keeps out of your way. A group can also carry a color, which takes over the display of every tag inside it; your own tag colors are kept, and removing the group color brings them straight back. Groups are made and organized on the Tags Manager, in Settings > Tags.

Common Uses

  • Roles: Protagonist, Antagonist, Supporting
  • Status: Alive, Dead, Unknown
  • Affiliation: Team A, Team B, Neutral
  • Abilities: Magic User, Fighter, Healer
  • Development: Needs Work, Complete
  • Cross-content markers: "Act 1", "Needs Revision", "Important Plot Point"

Tip: Tags work across your entire book. A tag created for characters is automatically available for locations, items, chapters, and notes.

Configuration

To view the Tags Block settings, go to Settings > Character Sheet Setup and click on the Tags section.

The Tags Block's only setting is Include in Quick Create. Quick Create is the short form you get when adding a character in a hurry; turn this on and the Tags Block appears on it. Everything else about tags (creating, renaming, deleting, colors, and groups) is handled in one place, on the Tags Manager.

Manage all tags in Settings > Tags. Learn more about creating and managing tags in Managing Tags.

Note: Only one Tags Block allowed per character layout.
